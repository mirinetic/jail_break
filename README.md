# Cove

Android TV / Google TV용 개인 홈 화면(런처) 앱이에요. 내 TV에 직접 설치(사이드로딩)해서 쓰는 용도이고, 플레이스토어 배포용이 아니에요.

웹페이지를 TV 브라우저로 여는 방식이 아니라 **TV에 설치되는 진짜 앱**이에요. 그래서 타일을 누르면 넷플릭스, 유튜브 같은 **TV 앱이 그대로 실행**돼요.

## 기능

| 기능 | 내용 |
|---|---|
| 앱 타일 | TV에 설치된 앱을 자동으로 찾아 실제 배너와 아이콘으로 보여줘요. 브랜드 색은 로고에서 자동으로 뽑아요 |
| 모든 앱 | 위쪽 **모든 앱** 버튼으로 설치된 앱 전체를 보고 실행해요 |
| 앱 메뉴 | 타일에서 **OK를 길게** 누르면: 실행, 홈에 추가·빼기, 위치 옮기기, 앱 정보, 앱 삭제 |
| 새 앱 자동 추가 | 새로 설치한 앱이 홈 끝에 자동으로 붙어요 (꾸미기에서 끌 수 있어요) |
| 디자인 3종 | **Glass**(사진 위 유리 타일), **Icons**(브랜드 컬러 아이콘), **Minimal**(큰 시계와 로고 한 줄) |
| 배경 | 코드로 그린 풍경 8장 (`tools/make_backgrounds.py`) + 폰에서 보낸 내 사진. **밤 배경**을 정하면 오후 7시부터 오전 6시까지 자동으로 바뀌어요 |
| 꾸미기 | 배경 어둡게 4단계, 타일 6종(앱 배너, 글래스, 브랜드 컬러, 프로스트, 다크, 투명), 앱 이름 표시, 글꼴 4종, 시계(24시간, 12시간, 숨김) |
| 카테고리 줄 | 홈 앱을 "영화·드라마", "음악" 같은 소제목 달린 줄로 묶어요 (꾸미기 → 카테고리 줄). **최근 실행** 줄도 켤 수 있어요. Glass, Icons 디자인에서 보이고 Minimal은 한 줄 그대로예요 |
| 프로필 | 사람마다 디자인, 배경, 홈 앱 목록, 줄 구성을 따로 저장해요. 위쪽 프로필 버튼, 폰 리모컨, 음성으로 바꿔요 |
| PIN 잠금 | 설정 → 잠금 PIN (4자리). 프로필별로 "바꿀 때 PIN", "설정 잠그기"를 켤 수 있고, 앱 메뉴에서 앱 하나만 잠글 수도 있어요. 한 번 풀면 5분 동안 유지돼요 |
| 날씨 | 꾸미기 → 날씨에서 도시를 고르면 시계 아래에 현재 날씨와 최고·최저 기온이 나와요 ([Open-Meteo](https://open-meteo.com), 키 필요 없음) |
| 폰 리모컨 | 설정 화면의 QR을 폰으로 찍으면 방향키, OK(길게 누르면 앱 메뉴), 모든 앱, 디자인, 배경, 프로필, 내 사진 보내기 |
| 음성·문장 명령 | 폰 리모컨 입력창에 말하거나(키보드 마이크 버튼) 입력하면 TV가 알아들어요 |
| 업데이트 | 설정 → **업데이트 확인**에서 새 버전을 받아 바로 설치해요 |
| 홈 버튼 전환 | 접근성 권한을 켜면 홈 버튼이나 TV 전원을 켰을 때 Cove가 떠요 (선택 사항) |

TV 리모컨의 **메뉴 버튼**을 누르면 꾸미기 패널이 열려요.

### 음성·문장 명령 예시

| 말하기 | 하는 일 |
|---|---|
| "넷플릭스 틀어줘", "유튜브" | 앱 실행 |
| "유튜브 홈에서 빼줘", "티빙 추가해줘" | 홈 화면에서 빼기·추가 |
| "미니멀로 바꿔", "아이콘", "글래스" | 디자인 바꾸기 |
| "배경 다음", "오로라 배경", "어둡게", "밝게" | 배경 바꾸기 |
| "엄마 프로필", "새 프로필 만들어", "이름을 민수로 바꿔" | 프로필 |
| "모든 앱", "꾸미기", "설정", "닫아" | 화면 열기·닫기 |
| "새 줄 추가", "줄 이름을 영화로 바꿔", "넷플릭스 영화 줄로 옮겨", "최근 실행 줄 켜" | 카테고리 줄 |
| "날씨 부산", "날씨 꺼" | 날씨 |
| "1234" (PIN 화면이 떠 있을 때) | PIN 입력 |
| "시계 숨겨", "12시간 시계", "업데이트 확인" | 기타 |

명령은 인터넷 없이 TV 안에서 단어 규칙으로 해석해요. TV 리모컨의 마이크 버튼은 Google 어시스턴트가 쓰기 때문에 Cove 명령에는 쓰지 않아요.

### 폰 리모컨의 마이크 버튼

- **기본**: 마이크 버튼을 누르면 키보드가 열려요. 키보드의 마이크를 누르고 말하면, 말이 끝나고 1.5초 뒤 자동으로 TV에 보내요.
- **안드로이드 크롬에서 한 번 설정하면**: 마이크 버튼만 누르고 바로 말하면 돼요. 리모컨 화면의 **"마이크 버튼 한 번으로 바로 말하기"** 안내를 따라 `chrome://flags` → *Insecure origins treated as secure*에 리모컨 주소(`http://TV의IP:8765`)를 등록하고 크롬을 다시 시작해요. 복사 버튼과 주소가 안내 안에 다 들어 있어요.
- 브라우저는 `https`가 아닌 주소에서 마이크를 막기 때문에 이 설정이 필요해요. 아이폰 사파리와 삼성 인터넷은 이 설정이 없어서 키보드 마이크 방식으로 써요.
- TV IP가 바뀌면 안내가 다시 나타나요. 공유기에서 TV에 고정 IP(DHCP 예약)를 주면 다시 할 필요가 없어요.

## 버전과 되돌리기

- 빌드할 때마다 버전 번호가 1씩 올라가요 (`1.0.N`). Cove **설정 → 버전**에서 지금 버전을 볼 수 있어요.
- 모든 빌드는 **Releases**에 `Cove 1.0.N`으로 따로 보관돼요. 바뀐 내용도 함께 적혀 있어요.
- **이전 버전으로 되돌리기**: GitHub → Actions → **Build Cove APK** → **Run workflow** → `ref` 칸에 되돌릴 버전(예: `v1.0.3`)을 넣고 실행해요. 그 버전의 코드가 **새 번호**로 다시 빌드돼서 `cove-latest`에 올라가요. TV에서는 평소처럼 업데이트하면 되고 설정도 유지돼요.
- 안드로이드는 번호가 낮은 버전을 덮어 설치하지 못하게 막아요. 그래서 옛날 APK를 직접 설치하지 말고 위 방법으로 되돌리세요.

## APK 받기

`app/` 아래 코드가 바뀌어 푸시되면 GitHub Actions가 APK를 빌드해요.

- **최신 버전**: https://github.com/mirinetic/jail_break/releases/download/cove-latest/Cove.apk
- **지난 버전**: Releases의 `Cove 1.0.N`
- 이미 설치했다면 Cove **설정 → 업데이트 확인**이 가장 편해요. 처음 한 번은 Cove에 "출처를 알 수 없는 앱 설치"를 허용해야 해요.

## TV에 설치하기

APK 주소 (항상 최신 빌드):

```
https://github.com/mirinetic/jail_break/releases/download/cove-latest/Cove.apk
```

### 방법 1. TV에서 바로 받기 (Downloader 앱, 추천)

PC나 USB 없이 TV만으로 설치해요.

1. TV의 Google Play 스토어에서 **Downloader**(개발사 AFTVnews)를 설치해요.
2. **출처를 알 수 없는 앱 설치**를 Downloader에 허용해요: 설정 → 앱 → 보안 및 제한 → 출처를 알 수 없는 앱 → Downloader 켜기. 메뉴 이름은 TV마다 조금 달라요. 설치 중에 허용 창이 뜨면 거기서 허용해도 돼요.
3. Downloader 주소창에 위 APK 주소를 입력하고 **Go**를 눌러요.
4. 다운로드가 끝나면 **설치**를 눌러요. 새 버전도 같은 주소로 받아서 덮어 설치하면 설정이 유지돼요.

주소가 길어서 리모컨으로 입력하기 번거로우면, PC나 폰에서 [tinyurl.com](https://tinyurl.com) 같은 서비스로 위 주소의 단축 URL을 만들어 입력하면 돼요.

### 방법 2. PC에서 ADB로 설치

먼저 TV에서 **개발자 모드**를 켜요: 설정 → 시스템 → 정보 → **Android TV OS 빌드**를 7번 누르기.

1. TV 설정 → 시스템 → 개발자 옵션 → **USB 디버깅**(또는 네트워크 디버깅) 켜기
2. TV의 IP 주소 확인: 설정 → 네트워크 → 연결된 와이파이
3. PC에 [Android platform-tools](https://developer.android.com/tools/releases/platform-tools)를 설치하고:

```bash
adb connect 192.168.0.23:5555
```

```bash
adb install -r Cove.apk
```

TV에 "USB 디버깅을 허용할까요?"가 뜨면 **허용**을 눌러요. 숫자는 내 TV의 IP로 바꿔요.

### 방법 3. USB 메모리

APK를 USB 메모리에 넣어 TV에 꽂고, TV의 파일 관리자 앱으로 열어 설치해요. 처음 한 번 "출처를 알 수 없는 앱 설치"를 그 파일 관리자에게 허용해야 해요.

## 홈 버튼 누르면 Cove가 뜨게 하기

설치만 하면 앱 목록에 Cove가 하나 생겨요. 홈 화면 자체로 쓰려면 둘 중 하나를 해요.

**A. 접근성 방식 (PC 필요 없음)**
1. Cove 실행 → 오른쪽 위 **설정** → **홈 버튼으로 Cove 열기** 선택
2. TV 접근성 설정이 열리면 **Cove 홈 버튼 전환**을 켜요
3. 홈 버튼을 눌러 확인해요. 기본 홈이 아주 잠깐 보였다가 Cove로 바뀔 수 있어요.

Cove 설정에서 언제든 다시 끌 수 있어요. 이 기능은 어떤 앱이 앞에 떴는지만 확인하고, 화면 내용은 읽지 않아요.

**접근성을 켜자마자 다시 꺼지면**: Downloader나 USB로 설치한 앱은 안드로이드 13부터 접근성 권한이 막혀요("제한된 설정"). TV 설정 → 앱 → Cove에서 **제한된 설정 허용**을 누르고 다시 켜요. 그 메뉴가 없으면 PC에서:

```bash
adb shell appops set com.mirinetic.cove ACCESS_RESTRICTED_SETTINGS allow
```

Cove 설정 화면의 **권한이 켜지지 않을 때**에도 같은 안내가 있어요.

**B. ADB 방식 (기본 홈을 끄기)**

Cove를 먼저 설치한 다음에 해요.

```bash
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
```

되돌리기:

```bash
adb shell pm enable com.google.android.apps.tv.launcherx
```

기본 홈을 끄면 Google 계정 추천이나 Google Home 연동 같은 일부 기능이 이상해질 수 있어요. 구형 Android TV는 패키지 이름이 `com.google.android.tvlauncher`일 수 있어요.

## PIN 잠금 쓰는 법 (예: 아이 프로필)

1. 설정 → **잠금 PIN**에서 4자리를 두 번 입력해요.
2. 프로필 → **새 프로필 추가**로 "아이" 프로필을 만들고, 그 프로필에서 **이 프로필의 설정 잠그기**를 켜요.
3. 부모 프로필로 바꾼 뒤 **이 프로필로 바꿀 때 PIN**을 켜요.
4. 필요하면 아이 프로필에서 특정 앱의 앱 메뉴(OK 길게) → **잠금**을 켜요.

이제 아이 프로필에서는 꾸미기, 설정, 모든 앱, 앱 삭제와 부모 프로필 전환에 PIN이 필요해요. TV 자체 설정 등 Cove 밖의 화면까지 막지는 못하는 가벼운 잠금이에요. PIN을 잊어버리면 TV 설정 → 앱 → Cove → 데이터 삭제로 초기화해요 (Cove 설정이 모두 지워져요).

## 폰 리모컨

Cove 설정을 열면 QR 코드가 보여요. 폰 카메라로 찍으면 리모컨 페이지가 열려요.

- 폰과 TV가 **같은 와이파이**에 있어야 해요.
- 리모컨 서버는 TV의 8765 포트에서 돌아가고, QR 주소에 들어 있는 연결 코드가 있어야만 명령을 받아요.
- Cove 설정 화면에서 리모컨 서버가 실행 중인지, TV의 네트워크 주소가 무엇인지 볼 수 있어요. 연결이 안 되면 폰 브라우저에 그 주소를 직접 입력해 보세요.
- 게스트 와이파이나 기기끼리 통신을 막는 공유기 설정(AP 격리)에서는 연결되지 않아요.
- **폰 사진을 TV 배경으로**를 누르면 사진이 TV 안에만 저장돼요. 인터넷으로 나가지 않아요.

## 미리보기 (TV 없이)

`app/src/main/assets/www/index.html`을 PC 브라우저로 열면 샘플 앱으로 화면을 볼 수 있어요. 방향키로 이동, Enter로 선택, Shift+Enter(또는 `l`)로 OK 길게 누르기, Esc로 뒤로, `m`으로 꾸미기 패널을 열어요. 개발자 도구 콘솔에서 `Cove.say('미니멀로 바꿔')`처럼 음성 명령도 시험할 수 있어요.

## 구조

```
app/src/main/java/com/mirinetic/cove/
  MainActivity.kt         홈 화면. 리모컨 키를 화면으로 전달하고, 홈 버튼에 반응
  AppRepository.kt        설치된 TV 앱 목록, 배너와 아이콘, 브랜드 색
  Bridge.kt               화면(JavaScript) ↔ TV 연결: 앱 실행, 설정 저장
  LocalContent.kt         화면 파일과 앱 이미지를 앱 안에서 제공 (네트워크 사용 안 함)
  RemoteServer.kt         폰 리모컨용 작은 웹서버
  HomeOverrideService.kt  홈 버튼 전환 (접근성 서비스)
  Updater.kt              앱 안 업데이트 (version.json 확인, APK 설치)
  Store.kt, Qr.kt         설정과 사진 저장, QR 코드
app/src/main/assets/www/  TV 화면(index.html, app.css, app.js)과 폰 리모컨(remote.html), 배경 이미지
tools/make_backgrounds.py 배경 이미지 생성 스크립트
```

## 서명 키

`keystore/cove-personal.jks`는 개인 설치용 고정 키예요. 매번 같은 키로 서명해서 새 버전을 설치해도 설정이 유지돼요. 비밀번호가 빌드 파일에 그대로 들어 있으니 이 키로 서명한 앱을 다른 사람에게 배포하지 마세요.

Android Studio로 이 폴더를 열고 Run을 누르거나, Android SDK가 있는 PC에서:

```bash
./gradlew assembleRelease
```
