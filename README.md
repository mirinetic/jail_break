# Cove

Android TV / Google TV용 개인 홈 화면(런처) 앱이에요. 내 TV에 직접 설치(사이드로딩)해서 쓰는 용도이고, 플레이스토어 배포용이 아니에요.

웹페이지를 TV 브라우저로 여는 방식이 아니라 **TV에 설치되는 진짜 앱**이에요. 그래서 타일을 누르면 넷플릭스, 유튜브 같은 **TV 앱이 그대로 실행**돼요.

## 기능

| 기능 | 내용 |
|---|---|
| 앱 타일 | TV에 설치된 앱을 자동으로 찾아 실제 배너와 아이콘으로 보여줘요. 브랜드 색은 로고에서 자동으로 뽑아요 |
| 모든 앱 | 위쪽 **모든 앱** 버튼으로 설치된 앱 전체를 보고 실행해요 |
| 앱 메뉴 | 타일에서 **OK를 길게** 누르면: 실행, 홈에 추가·빼기, 위치 옮기기, 앱 정보, 앱 삭제 |
| 새 앱 자동 추가 | 새로 설치한 앱이 홈 끝에 자동으로 붙어요 (꾸미기에서 끌 수 있어요) |
| 디자인 7종 | **Glass**(사진 위 유리 타일), **Icons**(브랜드 컬러 아이콘), **Minimal**(큰 시계와 로고 한 줄), **Theater**(고른 앱을 크게, 앱 색 배경), **Column**(왼쪽 줄 목록, 오른쪽 앱), **Dock**(큰 시계와 아래 아이콘 독), **Collage**(크고 작은 타일 배열) |
| 배경 | 코드로 그린 풍경 16장 (`tools/make_backgrounds.py`, 고화질 2장 **여명 바다**·**고리 행성**은 `tools/make_premium_backgrounds.py`), 움직이는 배경 3종(흐르는 빛, 반짝이는 별, 내리는 눈), 단색·그라데이션 8종, **고른 앱 색**(선택한 앱의 배너를 흐리게), 폰에서 보낸 내 사진. **밤 배경**을 정하면 오후 7시부터 오전 6시까지 자동으로 바뀌어요 |
| 꾸미기 | 배경 어둡게 4단계, 타일 10종(앱 배너, 글래스, 브랜드 컬러, 그라데이션, 네온, 프로스트, 다크, 흑백, 포스터, 투명), 타일 모양(둥근 사각형, 원형, 알약형, 각진 모양), 타일 크기(작게, 보통, 크게), 앱 이름 표시, 글꼴 4종, 시계(24시간, 12시간, 숨김) |
| 카테고리 줄 | 홈 앱을 "영화·드라마", "음악" 같은 소제목 달린 줄로 묶어요 (꾸미기 → 카테고리 줄). **최근 실행** 줄도 켤 수 있어요. Glass, Icons 디자인에서 보이고 Minimal은 한 줄 그대로예요 |
| 프로필 | 사람마다 디자인, 배경, 홈 앱 목록, 줄 구성을 따로 저장해요. 새 프로필은 확인 화면을 거쳐 **기본 상태**로 시작해요 (지금 설정 복사도 선택 가능). 위쪽 프로필 버튼, 폰 리모컨, 음성으로 바꿔요 |
| 나의 프로필 (마이 룸) | 위쪽 프로필 버튼 → **나의 프로필** (폰 리모컨, 음성 "내 프로필"). 큰 프로필 아이콘과 함께 사용 시간 링과 7일 막대그래프, 내 홈 화면 축소판, 작은 달력과 다가오는 일정, 포스트잇 메모, 시네마 포스터와 진행 바, 짝꿍 카드 트로피를 한 화면에 보여줘요. 각 영역에서 OK를 누르면 그 기능으로 가고, 뒤로 누르면 돌아와요 |
| 마스터 프로필 | 처음 프로필이 마스터예요. PIN, 프로필 추가·삭제, 키즈 설정, 앱 잠금, 앱 삭제, 홈 버튼 전환, 업데이트 설치는 마스터만 해요. 다른 프로필에서는 PIN을 넣으면 5분 동안 마스터로 처리돼요 |
| 키즈 프로필 | 마스터가 허용한 앱만 보이고 열려요 (홈, 모든 앱, 음성 모두). 나가려면 PIN이 필요하고, 꾸미기 허용 여부도 마스터가 정해요 |
| PIN 잠금 | 설정 → 잠금 PIN (4자리, 마스터). 프로필별 "바꿀 때 PIN", 앱 메뉴의 앱 잠금. 한 번 넣으면 5분 동안 유지돼요 |
| 일정 | 위쪽 **일정** 버튼: 하루 / 이번 주 / 한 달 보기. 폰 리모컨이나 음성으로 일정을 추가하고, **Google 캘린더·아이폰(iCloud) 캘린더를 구독 주소로 연결**해요 (로그인 없이, 읽기 전용). 홈 화면 시계 아래에 다음 일정이 한 줄로 나와요 |
| 메모 | 위쪽 **메모** 버튼의 메모판에 쪽지를 붙여요 (TV 키보드, 폰 리모컨, 음성 "메모 남겨 6시에 저녁 먹자"). 최근 메모가 시계 아래에 한 줄로 나와요 |
| 화면 보호기 | 사진 슬라이드(천천히 확대), 시계, 날씨, 다가오는 일정, 메모. **TV 화면 보호기**로 쓰거나, Cove 홈을 그대로 두면 나오는 **대기 화면**으로 써요 (설정 → 화면 보호기 · 대기 화면) |
| 일정·메모 타일 | 일정과 메모도 홈의 앱 타일로 열어요. 타일에 오늘 날짜와 다음 일정, 새 메모 수와 첫 줄이 바로 보여요. 줄에 넣기, 옮기기, 빼기, 키즈 허용, 잠금도 다른 앱과 같아요. 위쪽 일정·메모 버튼은 꾸미기 → **위쪽 일정·메모 버튼**에서 숨길 수 있어요 |
| 미니 앱 | Cove 안에서 도는 앱: **Cove 시네마**(가상 OTT, 이어 보기·찜·키즈 관람가 필터), **짝꿍 카드**(같은 그림 찾기), **창가의 작은 섬**(진짜 시간으로 자라는 섬 키우기). 프로필마다 기록이 따로 남아요 |
| 사용 기록 · 시간 제한 | 프로필별 앱 사용 시간과 열기 횟수. 프로필마다 **하루 사용 시간**을 정하면 다 쓴 뒤에는 앱이 열리지 않고, PIN으로 30분씩 늘려요 |
| 시계 · 날씨 위젯 | 홈의 시계와 날씨는 위젯이에요. OK를 누르면 탁상시계와 자세한 날씨(24시간 · 7일 예보) 화면이 열리고, 위젯은 앱을 가리지 않는 빈자리 안에서 옮길 수 있어요 ([Open-Meteo](https://open-meteo.com), 키 필요 없음) |
| 폰 리모컨 | 아래 탭(리모컨 · 꾸미기 · 일정 · 메모)으로 나뉜 앱 형태예요. 설정 → 폰 리모컨의 QR을 폰으로 찍으면 방향키, OK(길게 누르면 앱 메뉴), 모든 앱, 디자인, 배경, 프로필, 내 사진 보내기 |
| 음성·문장 명령 | 폰 리모컨 입력창에 말하거나(키보드 마이크 버튼) 입력하면 TV가 알아들어요 |
| 업데이트 | 설정 → **업데이트 확인**에서 새 버전을 받아 바로 설치해요 |
| 홈 버튼 전환 | 접근성 권한을 켜면 홈 버튼이나 TV 전원을 켰을 때 Cove가 떠요 (선택 사항) |

TV 리모컨의 **메뉴 버튼**을 누르면 꾸미기 패널이 열려요. 위쪽 일정·메모 버튼은 기본으로 숨겨져 있고, 꾸미기 → 시계 · 정보에서 켤 수 있어요.

### 음성·문장 명령 예시

| 말하기 | 하는 일 |
|---|---|
| "넷플릭스 틀어줘", "유튜브" | 앱 실행 |
| "유튜브 홈에서 빼줘", "티빙 추가해줘" | 홈 화면에서 빼기·추가 |
| "미니멀로 바꿔", "아이콘", "글래스", "시어터", "칼럼", "도크", "콜라주" | 디자인 바꾸기 |
| "네온 타일", "포스터 타일", "원형", "알약형", "타일 크게" | 타일 |
| "배경 다음", "오로라 배경", "내리는 눈", "노을 그라데이션", "앱 색 배경", "어둡게", "밝게" | 배경 바꾸기 |
| "엄마 프로필", "새 프로필 만들어", "이름을 민수로 바꿔" | 프로필 |
| "모든 앱", "꾸미기", "설정", "닫아" | 화면 열기·닫기 |
| "새 줄 추가", "줄 이름을 영화로 바꿔", "넷플릭스 영화 줄로 옮겨", "최근 실행 줄 켜" | 카테고리 줄 |
| "날씨 부산", "날씨 꺼" | 날씨 |
| "오늘 일정", "내일 일정 보여줘", "이번 주 스케줄", "달력" | 일정 보기 |
| "내일 오후 3시 치과 추가", "금요일 7시 가족 저녁 등록", "다음 주 화요일 10시 반 회의 추가", "11월 20일 엄마 생일 추가" | 일정 추가 |
| "메모 남겨 6시에 저녁 먹자", "메모 보여줘" | 메모 |
| "화면 보호기" | 대기 화면 바로 보기 |
| "1234" (PIN 화면이 떠 있을 때) | PIN 입력 |
| "시계 숨겨", "12시간 시계", "업데이트 확인" | 기타 |

명령은 인터넷 없이 TV 안에서 단어 규칙으로 해석해요. TV 리모컨의 마이크 버튼은 Google 어시스턴트가 쓰기 때문에 Cove 명령에는 쓰지 않아요.

### 일정 (캘린더)

- **보기**: 위쪽 **일정** 버튼(오늘이 선택된 한 달 보기로 열려요), 폰 리모컨의 **일정** 버튼, 또는 "오늘 일정"처럼 말하기
  - 방향키로 날짜를 옮기고 **OK**로 그날을 열어요. 하루 보기에서는 ▲ ▼로 일정을 고르고 **OK**로 열어요
  - 맨 위 줄(▲로 이동): 하루 · 이번 주 · 한 달, **＋ 일정 추가**, **캘린더 설정**
  - **뒤로**: 열어 본 날에서 달력으로 돌아가고, 한 번 더 누르면 닫혀요
- **추가**: TV에서 **＋ 일정 추가** (제목은 TV 키보드로, 키보드의 마이크로 말해도 돼요), 폰 리모컨 → 일정, 또는 음성. 시간을 비우면 종일 일정이에요
- **수정·삭제**: 하루 보기에서 내 일정을 골라 OK. 구독 캘린더 일정은 원래 캘린더에서 바꿔요
- **누구 일정**: "가족 모두(공용)"는 모든 프로필에, 개인 일정은 그 프로필에서만 보여요. TV와 음성으로 추가하면 **지금 프로필의 개인 일정**이 기본이고, "가족 저녁"처럼 가족·우리·모두를 말하거나 고르면 공용이 돼요. 폰에서는 TV에 켜져 있는 프로필이 기본으로 골라져요

**Google·아이폰 캘린더 연결** (폰 리모컨 → 일정 → 구독 캘린더 연결)

- Google: PC 브라우저에서 calendar.google.com → 설정 → 내 캘린더의 설정에서 캘린더 선택 → 캘린더 통합 → **iCal 형식의 비공개 주소** 복사
- 아이폰: 캘린더 앱 → 캘린더 → 연결할 캘린더의 ⓘ → **공개 캘린더** 켜기 → 링크 공유 → 복사 (webcal:// 주소)
- 주소를 붙여넣으면 TV가 30분마다 불러와요. 반복 일정, 종일 일정, 시간대가 들어간 일정을 처리해요
- **읽기 전용**이에요. Cove에서 추가한 일정은 Google·아이폰 캘린더로 올라가지 않아요. Google 쪽 변경은 반영까지 몇 시간 걸릴 수 있어요
- 구독 주소를 아는 사람은 일정을 볼 수 있어요. TV 안에만 저장하고 TV 화면에는 보여주지 않아요

## 홈 위젯 (시계 · 날씨)

- 홈 화면의 **시계**와 **날씨**는 위젯이에요. 방향키로 위젯에 가서 **OK**를 누르면 전용 화면이 열려요.
  - **탁상시계**: 디지털 · 아날로그 · 플립 모양(◀ ▶로 바꿔요), 날짜와 날씨, 다음 일정. 밤 10시부터 아침 6시까지는 은은하게 어두워져요. 아래 **⚙ 시계 설정**(▼ 후 OK)에서 시간 형식(12/24시간), 초 표시, 밤에 어둡게, 시간대(마스터)를 바꿔요.
  - **날씨**: 지금 날씨, 체감 온도 · 습도 · 바람 · 강수 확률 · 해 뜨고 지는 시각, **앞으로 24시간 기온과 비 올 확률**, **이번 주 7일 예보**. ◀ ▶로 도시를 바꾸고, ⚙ 날씨 설정에서도 고를 수 있어요.
- **위젯 자리**: 위젯은 디자인마다 앱이 차지하지 않는 빈 곳에 놓여요(Minimal · Dock은 가운데 크게, 나머지는 위쪽). 위젯에서 **OK 길게** → **위치 옮기기**로 방향키로 옮기고 OK로 확정, 뒤로 취소해요. 앱이나 다른 위젯과 겹치는 자리는 피해서 가장 가까운 빈자리로 가고, 자리가 정말 없으면 숨어요. 위치는 디자인마다 따로 기억해요.
- 꾸미기 → **시계 · 위젯**에서 위젯을 켜고 끄고, 자리를 처음대로 돌릴 수 있어요.
- 음성: "시계 보여 줘", "이번 주 날씨 어때", "부산 날씨"

## 화면 보호기 · 메모

**화면 보호기** (설정 → 화면 보호기 · 대기 화면)

- 사진(배경 사진 모두 / 내 사진만 / 지금 배경), 넘김 간격, 시계·날씨, 일정·메모 표시를 고를 수 있어요
- **Cove 대기 화면**: Cove 홈을 정해 둔 시간(5·10·30분) 동안 그대로 두면 나와요. 아무 버튼이나 누르면 돌아와요
- **TV 화면 보호기**: 다른 앱을 쓰다 TV가 쉴 때도 나와요. 설정의 **TV 화면 보호기로 쓰기**에서 Cove를 골라요. 일부 Google TV는 이 목록을 숨겨 두는데, 그때는 한 번만:

```bash
adb shell settings put secure screensaver_components com.mirinetic.cove/.CoveDream
```

- 시계와 글자가 1분마다 조금씩 자리를 옮겨서 OLED 화면 잔상을 줄여요

**메모**

- 위쪽 **메모** 버튼 → **＋ 메모 붙이기** (TV 키보드), 또는 폰 리모컨 → 메모, 또는 "메모 남겨 …"라고 말하기
- 메모마다 **보내는 사람**(쓴 프로필), **받는 사람**(가족 모두 / 한 프로필), **보이는 날**, **보이는 기간**(지울 때까지, 하루, 3일, 1주일, 한 달)을 정해요
- 받는 사람에게, 보이는 날에만 홈 화면·메모판·화면 보호기에 나와요. 보낸 사람의 메모판에는 아직 안 보이는 메모나 다른 사람에게 보낸 메모도 흐리게 보여요. 끝난 메모는 1주일 뒤 자동으로 정리돼요
- 음성: "엄마에게 메모 남겨 우유 사 와", "내일 메모 남겨 쓰레기 버리기"
- 메모를 골라 OK: 내용, 받는 사람, 날짜, 기간, 색 고치기, 떼기
- 홈 화면 시계 아래와 화면 보호기에 최근 메모가 나와요 (꾸미기 → 메모에서 끌 수 있어요)

## 메뉴와 조작

- **꾸미기**: 디자인 / 배경 / 타일 / 홈 앱 · 줄 / 시계 · 정보. **설정**: 폰 리모컨 / 시간 · 지역 / 화면 보호기 · 대기 화면 / 캘린더 / 가족 · 프로필 / 시스템 / 업데이트 · 정보. 첫 화면에는 분류와 지금 값이 요약으로 보이고, OK로 들어가요.
- **권한에 맞게 보여요**: 그 프로필이 쓸 수 없는 분류와 줄은 아예 안 보여요. 마스터가 아닌 프로필에는 **마스터 메뉴 열기** 한 줄만 있고, PIN을 넣으면 5분 동안 모든 메뉴가 보여요.
- **저장 / 취소**: 설정 화면에서 바꾼 것은 바로 미리 보이고, 맨 아래 **저장**을 눌러야 확정돼요. 저장하지 않고 뒤로 가면 "저장할까요?"를 물어요. 홈 버튼을 누르면 저장하지 않은 변경은 되돌아가요. 앱 위치 옮기기는 OK로 확정, 뒤로로 취소해요.
- **◀ ▶와 OK**: 값은 ◀ ▶로만 바뀌고 끝에서 처음으로 돌아가요. OK는 들어가기와 입력에만 써요.
- **방향키**: ◀ ▶는 같은 줄 안에서만 움직이고 끝에서 멈춰요 (여러 줄 그리드는 다음 줄로 이어져요). 위쪽 메뉴줄, 탭, 앱 줄 사이는 ▲ ▼로 옮겨 다니고, 돌아오면 마지막에 있던 자리로 가요.
- **글자 입력**: Cove 자체 키보드로 한글(자모를 고르면 글자로 자동 조합), 영어, 숫자를 써요. 리모컨 숫자키는 숫자로 들어가고, 뒤로는 한 글자씩 지우다가 비면 닫아요. 키보드가 열려 있을 때 폰 리모컨 입력창에 쓰면 그대로 들어가요.
- **시간대**: 설정 → 시간 · 지역. TV 자체 시간대가 다른 나라로 되어 있어도 Cove의 시계, 일정, 메모, 사용 기록, 화면 보호기는 여기 정한 시간대(기본 서울)를 따라요.

## 미니 앱 (Cove 안에서 도는 앱)

TV에 설치하지 않아도 되는 Cove 전용 앱이에요. 다른 앱처럼 홈 화면과 모든 앱에 있어요. OK로 열고, 첫 화면에서 **뒤로**를 누르면 Cove로 돌아와요 (TV 홈 버튼은 언제나 바로 돌아와요). 프로필마다 기록이 따로 저장돼요.

- **Cove 시네마**: 가상 OTT 연습용 앱이에요. 작품과 영상은 모두 Cove가 그린 가상의 것이에요. 추천·장르 줄, 상세 화면, 재생(OK 일시정지, ◀ ▶ 30초 이동), **이어 보기**, **찜하기**가 있어요. 키즈 프로필에서는 **전체 관람가** 작품만 보여요.
- **짝꿍 카드**: 같은 그림 두 장을 찾는 카드 게임이에요. 시간 제한도 빠른 반응도 필요 없어요. 쉬움 3×4, 보통 4×4, 어려움 4×5 중에서 골라요. 프로필마다 단계별 최고 기록(뒤집기 횟수, 시간)이 남아요. 게임 중 **뒤로**를 두 번 누르면 단계 고르기로 나가요.
- 음성: "시네마 틀어줘", "짝꿍 카드 열어줘"
- 홈에서 바로 재생: **"보던 거 이어 보기 해 줘"**(가장 최근에 보다 만 작품을 멈춘 곳부터), **"찜한 거 틀어 줘"**(가장 최근에 찜한 작품), **"달빛 정원 틀어 줘"**·**"모모 보여 줘"**(제목이나 제목 일부). 키즈 프로필에서는 전체 관람가 작품만 재생돼요.
- **일정**과 **메모** 타일도 같은 방식으로 홈에 있어요. 열면 위쪽 버튼과 같은 일정·메모 화면이 나와요. 시간 제한과 상관없이 늘 열려요.
- 업데이트로 처음 생기면 "새 앱 자동 추가"를 켠 프로필의 홈에 들어가요. 키즈 프로필에서는 허용 앱으로도 추가돼요 (마스터가 허용 앱에서 뺄 수 있어요).

## 창가의 작은 섬 (미니 앱)

진짜 시간으로 자라는 나만의 섬이에요. 하루에 몇 번, 몇 분씩 들르는 게임이에요. 오래 비워도 시들거나 벌칙이 없어요.

- **조작**: 방향키로 섬을 둘러보고, **OK** 한 번이면 그 자리에 맞는 일을 해요(심기, 물 주기, 수확, 줍기, 손님과 이야기). 맨 아래까지 내려가면 **도구줄**(심기 · 만들기 · 꾸미기 · 상점 · 의뢰 · 도감 · 가족 · 우편)이 나와요.
- **자라는 것**: 작물 14종(계절 한정 포함)과 나무 6종. 작물은 물을 줘야 자라기 시작하고, 나무는 정해진 시간마다 열매가 열려요. 나무에서 나무토막도 나와요.
- **모래사장**: 90분마다 조개, 돌, 나무토막, 가끔 진주가 떠밀려 와요.
- **건축**: 도구줄 → **건축**에서 바닥 5종(돌길, 나무 데크, 모래길, 꽃길, 벽돌 바닥), 담 5종(나무 울타리, 흰 울타리, 돌담, 생울타리, 벽돌담), 문 2종(나무 문, 돌 아치 문)을 한 칸씩 지어요. 붙여 지으면 길과 담이 이어지고, 담 위에 문을 지으면 그 자리에 문이 달려요. 같은 칸에서 OK를 한 번 더 누르면 허물고 재료를 돌려받아요. 재료는 칸마다 들어요.
- **만들기와 꾸미기**: 가구 27종(울타리, 벤치, 풍차, 우물, 오두막, 회전목마, 관람차, 계절 가구…). 만든 가구를 섬에 놓고, 치우기로 다시 가방에 넣어요.
- **손님 20종**: 손님마다 좋아하는 것이 있어서(벤치, 사과나무와 텐트, 밤의 등불, 비 오는 날의 분수…) 조건이 맞으면 놀러 와서 하루쯤 머물러요. 이야기하면 선물을 주고 도감에 올라가요.
- **의뢰와 목표**: 날마다 의뢰 3개, 매주 목표 4가지(수확, 만들기, 손님, 의뢰). 주간 목표를 다 채우면 조개 300개와 트로피를 받아요.
- **섬 레벨 1~10**: 레벨 1부터 수십 칸의 땅이 있고, 레벨이 오를수록 해안선이 넓어지고 새 씨앗, 나무, 가구, 손님이 열려요.
- **진짜 시간·날씨·계절**: 섬의 낮과 밤은 Cove 시간대를 따라요. 꾸미기 → 시계 · 정보에서 정한 **도시의 실제 날씨**를 따라 비가 오면 물이 저절로 주어지고, 맑은 낮에는 20% 빨리 자라요. 계절(봄 벚꽃, 가을 단풍, 겨울 눈)과 계절 한정 작물·가구가 있어요.
- **가족**: 가족 → 다른 프로필의 섬에 **놀러 가서** 물을 주고 선물을 두고 와요(받은 사람의 우편함에 도착해요). 모두 함께 재료를 모아 **가족 등대**(5단계)를 지으면, 모든 섬에 등대가 서고 작물이 10% 빨리 자라요.
- **음성** (폰 리모컨 마이크나 입력창):
  - 홈에서 ("섬"을 넣어 말해요): "섬 어때", "섬에 누가 놀러 왔어", "섬에 물 줘", "섬 다 수확해 줘", "섬 손님이랑 이야기해 줘", "섬 모래사장 주워 줘", "섬에 당근 3개 심고 물 줘", "섬에서 딸기 씨앗 4개 사 줘", "섬에서 작물 다 팔아 줘", "섬 벤치 만들어 줘", "섬 의뢰 뭐야", "섬 의뢰 전해 줘"
  - 게임 중에는 "섬" 없이도 돼요: "다 수확해", "물 줘", "당근 2개 심어", "상점 열어", "도감 보여 줘", "엄마 섬에 놀러 가", (방문 중) "물 줘", "내 섬으로 가자". 섬과 상관없는 말("유튜브 틀어 줘")은 평소처럼 Cove가 처리해요.
- **Cove와 함께**: 홈 타일에 할 일 수가 배지로 떠요. 나의 프로필에 내 섬이 보이고, 화면 보호기 → 사진을 **내 섬**으로 고르면 대기 화면에서 섬이 잔잔하게 움직여요. 음성 "섬 열어", "섬에 물 줘"도 돼요.

## 사용 기록 · 하루 사용 시간

설정 → **가족 · 프로필** → **사용 기록 · 시간 제한** (마스터, 프로필 관리에서도 열려요. 자기 사용 기록은 나의 프로필에서 누구나 볼 수 있어요)

- 프로필마다 오늘과 최근 7일 사용 시간, 앱별 시간과 열어 본 횟수, 마지막 사용 시각을 보여줘요. 시네마에서 본 작품과 짝꿍 카드 최고 기록도 함께 보여요.
- 미니 앱 시간은 정확하게 재요. TV 앱 시간은 Cove를 떠났다가 돌아오기까지의 시간으로 **어림잡아요** (한 번에 최대 3시간까지만 세요).
- **하루 사용 시간** (끄기 / 15분 / 30분 / 1시간 / 1시간 30분 / 2시간 / 3시간): 정한 시간을 다 쓰면 그 프로필에서 앱이 열리지 않아요. 미니 앱은 쓰는 중에도 닫혀요. 5분 남으면 알려줘요. 어른이 PIN을 넣으면 30분씩 늘어나요. 마스터 프로필에는 제한을 걸 수 없어요.
- 이미 열려 있는 TV 앱(넷플릭스 등)은 Cove가 끌 수 없어요. 제한은 Cove에서 앱을 **새로 열 때** 적용돼요.

## 폰 리모컨의 마이크 버튼

- **기본**: 마이크 버튼을 누르면 키보드가 열려요. 키보드의 마이크를 누르고 말하면, 말이 끝나고 1.5초 뒤 자동으로 TV에 보내요.
- **안드로이드 크롬에서 한 번 설정하면**: 마이크 버튼만 누르고 바로 말하면 돼요. 리모컨 화면의 **"마이크 버튼 한 번으로 바로 말하기"** 안내를 따라 `chrome://flags` → *Insecure origins treated as secure*에 리모컨 주소(`http://TV의IP:8765`)를 등록하고 크롬을 다시 시작해요. 복사 버튼과 주소가 안내 안에 다 들어 있어요.
- 브라우저는 `https`가 아닌 주소에서 마이크를 막기 때문에 이 설정이 필요해요. 아이폰 사파리와 삼성 인터넷은 이 설정이 없어서 키보드 마이크 방식으로 써요.
- TV IP가 바뀌면 안내가 다시 나타나요. 공유기에서 TV에 고정 IP(DHCP 예약)를 주면 다시 할 필요가 없어요.

## 버전과 되돌리기

- 빌드할 때마다 버전 번호가 1씩 올라가요 (`1.0.N`). Cove **설정 → 버전**에서 지금 버전을 볼 수 있어요.
- 모든 빌드는 **Releases**에 `Cove 1.0.N`으로 따로 보관돼요. 바뀐 내용도 함께 적혀 있어요.
- **이전 버전으로 되돌리기**: GitHub → Actions → **Build Cove APK** → **Run workflow** → `ref` 칸에 되돌릴 버전(예: `v1.0.3`)을 넣고 실행해요. 그 버전의 코드가 **새 번호**로 다시 빌드돼서 `cove-latest`에 올라가요. TV에서는 평소처럼 업데이트하면 되고 설정도 유지돼요.
- 안드로이드는 번호가 낮은 버전을 덮어 설치하지 못하게 막아요. 그래서 옛날 APK를 직접 설치하지 말고 위 방법으로 되돌리세요.

## APK 받기

`app/` 아래 코드가 바뀌어 푸시되면 GitHub Actions가 APK를 빌드해요.

- **최신 버전**: https://github.com/mirinetic/jail_break/releases/download/cove-latest/Cove.apk
- **지난 버전**: Releases의 `Cove 1.0.N`
- 이미 설치했다면 Cove **설정 → 업데이트 확인**이 가장 편해요. 처음 한 번은 Cove에 "출처를 알 수 없는 앱 설치"를 허용해야 해요.

## TV에 설치하기

APK 주소 (항상 최신 빌드):

```
https://github.com/mirinetic/jail_break/releases/download/cove-latest/Cove.apk
```

### 방법 1. TV에서 바로 받기 (Downloader 앱, 추천)

PC나 USB 없이 TV만으로 설치해요.

1. TV의 Google Play 스토어에서 **Downloader**(개발사 AFTVnews)를 설치해요.
2. **출처를 알 수 없는 앱 설치**를 Downloader에 허용해요: 설정 → 앱 → 보안 및 제한 → 출처를 알 수 없는 앱 → Downloader 켜기. 메뉴 이름은 TV마다 조금 달라요. 설치 중에 허용 창이 뜨면 거기서 허용해도 돼요.
3. Downloader 주소창에 위 APK 주소를 입력하고 **Go**를 눌러요.
4. 다운로드가 끝나면 **설치**를 눌러요. 새 버전도 같은 주소로 받아서 덮어 설치하면 설정이 유지돼요.

주소가 길어서 리모컨으로 입력하기 번거로우면, PC나 폰에서 [tinyurl.com](https://tinyurl.com) 같은 서비스로 위 주소의 단축 URL을 만들어 입력하면 돼요.

### 방법 2. PC에서 ADB로 설치

먼저 TV에서 **개발자 모드**를 켜요: 설정 → 시스템 → 정보 → **Android TV OS 빌드**를 7번 누르기.

1. TV 설정 → 시스템 → 개발자 옵션 → **USB 디버깅**(또는 네트워크 디버깅) 켜기
2. TV의 IP 주소 확인: 설정 → 네트워크 → 연결된 와이파이
3. PC에 [Android platform-tools](https://developer.android.com/tools/releases/platform-tools)를 설치하고:

```bash
adb connect 192.168.0.23:5555
```

```bash
adb install -r Cove.apk
```

TV에 "USB 디버깅을 허용할까요?"가 뜨면 **허용**을 눌러요. 숫자는 내 TV의 IP로 바꿔요.

### 방법 3. USB 메모리

APK를 USB 메모리에 넣어 TV에 꽂고, TV의 파일 관리자 앱으로 열어 설치해요. 처음 한 번 "출처를 알 수 없는 앱 설치"를 그 파일 관리자에게 허용해야 해요.

## 홈 버튼 누르면 Cove가 뜨게 하기

설치만 하면 앱 목록에 Cove가 하나 생겨요. 홈 화면 자체로 쓰려면 둘 중 하나를 해요.

**A. 접근성 방식 (PC 필요 없음)**
1. Cove 실행 → 오른쪽 위 **설정** → **홈 버튼으로 Cove 열기** 선택
2. TV 접근성 설정이 열리면 **Cove 홈 버튼 전환**을 켜요
3. 홈 버튼을 눌러 확인해요. 기본 홈이 아주 잠깐 보였다가 Cove로 바뀔 수 있어요.

Cove 설정에서 언제든 다시 끌 수 있어요. 이 기능은 어떤 앱이 앞에 떴는지만 확인하고, 화면 내용은 읽지 않아요.

**접근성을 켜자마자 다시 꺼지면**: Downloader나 USB로 설치한 앱은 안드로이드 13부터 접근성 권한이 막혀요("제한된 설정"). TV 설정 → 앱 → Cove에서 **제한된 설정 허용**을 누르고 다시 켜요. 그 메뉴가 없으면 PC에서:

```bash
adb shell appops set com.mirinetic.cove ACCESS_RESTRICTED_SETTINGS allow
```

Cove 설정 화면의 **권한이 켜지지 않을 때**에도 같은 안내가 있어요.

**B. ADB 방식 (기본 홈을 끄기)**

Cove를 먼저 설치한 다음에 해요.

```bash
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
```

되돌리기:

```bash
adb shell pm enable com.google.android.apps.tv.launcherx
```

기본 홈을 끄면 Google 계정 추천이나 Google Home 연동 같은 일부 기능이 이상해질 수 있어요. 구형 Android TV는 패키지 이름이 `com.google.android.tvlauncher`일 수 있어요.

## 프로필, 마스터, 키즈

**권한 구분**

| 기능 | 마스터만 | 모든 프로필 |
|---|---|---|
| PIN 만들기·바꾸기·끄기, 마스터 넘기기 | ✓ | |
| 프로필 추가·삭제, "바꿀 때 PIN", 키즈 허용 앱·꾸미기 허용 | ✓ | |
| 앱 잠금, 앱 정보, 앱 삭제, 홈 버튼 전환, 업데이트 설치, TV 설정 | ✓ | |
| 내 꾸미기 (디자인, 배경, 타일, 날씨) | | ✓ (키즈는 마스터가 허용할 때) |
| 내 홈 앱 고르기, 카테고리 줄, 위치 옮기기 | | ✓ (키즈 제외) |
| 내 이름·색 | | ✓ (키즈 제외) |

다른 프로필에서 마스터 메뉴를 누르면 PIN을 물어요. 맞으면 그 자리에서 5분 동안 마스터로 처리돼요. 마스터 프로필로 들어갈 때도 PIN을 물어요.

**아이 프로필 만들기**

1. 마스터 프로필 → 설정 → **잠금 PIN**에서 4자리를 만들어요.
2. 프로필 → **새 프로필 추가** → 종류를 **키즈**로 바꾸고 **추가**를 눌러요. 유튜브 키즈처럼 아이용 앱이 있으면 처음부터 허용돼요.
3. 마스터 프로필 → 프로필 → **프로필 관리 · 아이** → **허용 앱**에서 보여줄 앱을 골라요. 필요하면 **아이가 꾸미기 바꾸기**를 막아요.
4. 아이는 키즈 프로필의 꾸미기 → **홈 앱 · 줄** → **앱 고르기**와 카테고리 줄로, **허용된 앱 안에서** 홈 화면을 자유롭게 정리할 수 있어요.

**프로필 버튼**: 위쪽 프로필 버튼을 누르면 프로필 고르기 창이 떠요 (오른쪽 끝 ＋로 추가, 아래 **나의 프로필**과 **프로필 설정**). 프로필 설정에는 그 프로필이 바꿀 수 있는 것만 보이고, 프로필 아이콘(이모지 27가지)도 여기서 골라요. 위쪽 프로필 버튼에 아이콘이 나와요. 자기 사용 기록은 누구나 볼 수 있고, 시간 제한을 바꾸는 건 마스터만 해요.

**프로필 관리** (마스터): 프로필마다 이름, 색, 종류(일반/키즈), 허용 앱, 꾸미기 허용, 바꿀 때 PIN, 삭제를 한곳에서 정해요. 다른 프로필에서 열면 PIN을 물어요.

키즈 프로필에서는 허용 앱만 보이고 열리며, 다른 프로필로 나가려면 PIN이 필요해요. Cove 화면 안에서만 막는 잠금이라, Google 어시스턴트나 TV 자체 메뉴로 여는 앱까지 막지는 못해요. PIN을 잊어버리면 TV 설정 → 앱 → Cove → 데이터 삭제로 초기화해요 (Cove 설정이 모두 지워져요).

## PIN 잠금 쓰는 법 (예: 아이 프로필)

1. 설정 → **잠금 PIN**에서 4자리를 두 번 입력해요.
2. 프로필 → **새 프로필 추가**로 "아이" 프로필을 만들고, 그 프로필에서 **이 프로필의 설정 잠그기**를 켜요.
3. 부모 프로필로 바꾼 뒤 **이 프로필로 바꿀 때 PIN**을 켜요.
4. 필요하면 아이 프로필에서 특정 앱의 앱 메뉴(OK 길게) → **잠금**을 켜요.

이제 아이 프로필에서는 꾸미기, 설정, 모든 앱, 앱 삭제와 부모 프로필 전환에 PIN이 필요해요. TV 자체 설정 등 Cove 밖의 화면까지 막지는 못하는 가벼운 잠금이에요. PIN을 잊어버리면 TV 설정 → 앱 → Cove → 데이터 삭제로 초기화해요 (Cove 설정이 모두 지워져요).

## 폰 리모컨

Cove 설정을 열면 QR 코드가 보여요. 폰 카메라로 찍으면 리모컨 페이지가 열려요.

- 폰과 TV가 **같은 와이파이**에 있어야 해요.
- 리모컨 서버는 TV의 8765 포트에서 돌아가고, QR 주소에 들어 있는 연결 코드가 있어야만 명령을 받아요.
- Cove 설정 화면에서 리모컨 서버가 실행 중인지, TV의 네트워크 주소가 무엇인지 볼 수 있어요. 연결이 안 되면 폰 브라우저에 그 주소를 직접 입력해 보세요.
- 게스트 와이파이나 기기끼리 통신을 막는 공유기 설정(AP 격리)에서는 연결되지 않아요.
- **폰 사진을 TV 배경으로**를 누르면 사진이 TV 안에만 저장돼요. 인터넷으로 나가지 않아요.

## 미리보기 (TV 없이)

`app/src/main/assets/www/index.html`을 PC 브라우저로 열면 샘플 앱으로 화면을 볼 수 있어요. 방향키로 이동, Enter로 선택, Shift+Enter(또는 `l`)로 OK 길게 누르기, Esc로 뒤로, `m`으로 꾸미기 패널을 열어요. 개발자 도구 콘솔에서 `Cove.say('미니멀로 바꿔')`처럼 음성 명령도 시험할 수 있어요.

```
app/src/main/java/com/mirinetic/cove/
  MainActivity.kt         홈 화면. 리모컨 키를 화면으로 전달하고, 홈 버튼에 반응
  AppRepository.kt        설치된 TV 앱 목록, 배너와 아이콘, 브랜드 색
  Bridge.kt               화면(JavaScript) ↔ TV 연결: 앱 실행, 설정 저장
  LocalContent.kt         화면 파일과 앱 이미지를 앱 안에서 제공 (네트워크 사용 안 함)
  RemoteServer.kt         폰 리모컨용 작은 웹서버
  HomeOverrideService.kt  홈 버튼 전환 (접근성 서비스)
  Updater.kt              앱 안 업데이트 (version.json 확인, APK 설치)
  Store.kt, Qr.kt         설정과 사진 저장, QR 코드
app/src/main/assets/www/  TV 화면(index.html, app.css, app.js)과 폰 리모컨(remote.html), 배경 이미지
app/src/main/assets/www/apps/  미니 앱: sdk.js(키 전달·프로필별 저장·가족 데이터), cinema.html, cards.html, island.html + island-core.js(섬 규칙과 그리기)
tools/make_backgrounds.py 배경 이미지 생성 스크립트
tools/make_premium_backgrounds.py  고화질 배경 2장 (여명 바다, 고리 행성)
tools/logo/               Cove 로고(cove-mark.svg)와 앱 아이콘·TV 배너 생성 (node tools/logo/render.js)
```

## 서명 키

`keystore/cove-personal.jks`는 개인 설치용 고정 키예요. 매번 같은 키로 서명해서 새 버전을 설치해도 설정이 유지돼요. 비밀번호가 빌드 파일에 그대로 들어 있으니 이 키로 서명한 앱을 다른 사람에게 배포하지 마세요.

Android Studio로 이 폴더를 열고 Run을 누르거나, Android SDK가 있는 PC에서:

```bash
./gradlew assembleRelease
```
